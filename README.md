# Cheese Run — Snake and Mouse Game

A simple Android game in which the player controls a snake and collects cheese while avoiding obstacles and hazards.

## Privacy Policy

The public Privacy Policy for the Android app is available at:

**https://parimalnarayan.github.io/Cheese-Run---Snake-and-Mouse-Game/**

## About this repository

This repository contains the public project and the privacy-policy website for Cheese Run. The privacy-policy site is deployed automatically to GitHub Pages using GitHub Actions whenever changes are pushed to `main`.

## Platform

- Android
- Google Play

## Privacy

Cheese Run does not require a player account. The app uses Google Firebase/Google Analytics for limited analytics and usage measurement where enabled. See the [Privacy Policy](./index.html) for details.
